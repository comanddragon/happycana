    Fix literal \\u2014 escape rendering as raw text in JSX
    
    Three spots had a \u2014 unicode escape sitting directly in JSX text
    content instead of inside a string literal. JS unicode escapes only
    resolve inside string/template literals — as bare JSX children they
    render as the literal 8-character sequence '\u2014' instead of an
    em dash. Swapped each for the actual — character:
    
    - app/blog/page.tsx: hero subhead
    - app/shop/new-arrivals/page.tsx: hero subhead
    - app/shop/best-sellers/page.tsx: hero subhead
    
    Everywhere else \u2014/\u2019 appear (metadata strings, FAQ arrays,
    guides.ts, blog.ts data) they're inside actual string literals, so
    JS already resolves them correctly at runtime — left those as-is.
