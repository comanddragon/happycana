Blog perf + SEO: cache/index/defer heavy queries, fix sitemap pagination + paginated canonical, per-post OG/Twitter + richer JSON-LD

Perf (why blog fetches were slow):
- Add composite index on (is_published, -published_at) — every list query
  filters/sorts on these with no index before now
- Store read_time on BlogPost (computed once in save()) instead of
  recomputing from full content_text on every list request
- Clean content_html once at write time instead of on every detail
  request; defer content_html/content_text on the list queryset entirely
- Cache blog list/detail responses in Redis using the same versioned-key
  pattern already used for categories (core/cache.py), invalidated via a
  post_save/post_delete signal
- Wire the raw-SQL scraper script (seed_blogs_direct_conn.py) to reuse the
  same cleaning/read-time helpers (apps/blog/utils.py) so scraped rows
  match ORM-written ones, and to populate the new read_time column
- Add backfill_blog_metadata management command for pre-existing rows

SEO (blog wiring gaps):
- Sitemap only listed page 1 of the blog (20 posts) — add getAllBlogPosts()
  to walk every page instead
- /blog paginated views (?page=N) all canonicalized back to /blog,
  telling search engines pages 2+ are duplicates — switch to
  generateMetadata so each page canonicalizes to itself
- /blog/[slug] had no per-post Open Graph/Twitter Card metadata — add it
  using the post's real image/description instead of the site default
- Article JSON-LD was missing image/publisher/dateModified — add them
  (exposing updated_at from the API for dateModified)
